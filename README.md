# Main Character Portfolio

A bold, editorial portfolio starter built around "main character energy": oversized typography, acid accents, dark editorial surfaces, grain, cursor glow, marquee motion, scroll reveals, and project-art blocks.

## Run
No build step required.

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For best results use VS Code + Live Server.

## Customize
- Replace `YOUR NAME`, `YC`, email, roles and achievement copy.
- Replace project cards and links in `projects.html`.
- Edit colors at the top of `styles.css`.
- Add real project images by replacing the `.project-art` blocks with `<img>` elements.
- Update Google Fonts if you want a different type system.

## Pages
- `index.html` — Home, About, Skills, Tech Stack, Experience, Achievements, Contact
- `projects.html` — Projects / selected work

## Design direction
Editorial + brutalist + art-direction portfolio, with main-character energy rather than a conventional resume layout.
